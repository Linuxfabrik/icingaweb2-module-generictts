# Icinga Web GenericTTS Integration

With the Icinga Web GenericTTS integration, Icinga Web replaces ticket references in acknowledgements, downtimes and comments with links to your trouble ticket systems. You configure one regular expression and one URL template per ticket system, for example to turn `#4711` into a link to ticket 4711.

The module was created by Icinga, who handed its maintenance over to [Linuxfabrik](https://www.linuxfabrik.ch/). Source code, issues and releases are on [GitHub](https://github.com/Linuxfabrik/icingaweb2-module-generictts).
